# Память Лины

## Три секции

1. Ядро задаётся в `data/settings.json` → `behavior`. Его версии сохраняются в `data/memory.sqlite3` → `core_versions` при запуске. Источник изменений — настройки владельца; извлечение воспоминаний не меняет ядро.
2. Опыт, факты и эмоциональные эпизоды остаются в `memory.sqlite3`. Таблица `memories` — оригиналы с UUID и источниками; `vectors` — перестраиваемый индекс. Смена model_id или текста вызывает повторное вычисление вектора. Поиск сочетает косинусную близость (80%) и совпадение слов (20%); важность и свежесть разрешают равные оценки.
3. Разговоры находятся в `data/conversations.sqlite3`. При первом открытии импортируются прежние JSON-сессии, исходники сохраняются. Сессии восстанавливаются после перезапуска. Сообщения, переданные в save, также сохраняются отдельно от скользящего контекста.

## Эмбеддинги

Выбрана пользователем `all-MiniLM-L6-v2`. Путь к локальному каталогу задаётся через `data/settings.json` → `embedding_model_path`. Если значение пустое, используется `EMBEDDING_MODEL` из `src/core/utils/local_paths.py`: `resources/models/embeddings/all-MiniLM-L6-v2` относительно корня LinaAI. Относительный путь настройки также отсчитывается от корня проекта. Нужен каталог Sentence Transformers с файлами модели и токенизатора. Загрузка ленивая, CPU, `local_files_only=True`: автоматического скачивания нет. Изменение пути применяется при следующем Start. Реальная модель проверена 23 октября 2026: 384 измерения, нормализация и семантический поиск на временной базе работают. При Stop модель и её рабочий поток освобождаются.

Индекс пока использует точный перебор векторов внутри выбранной зоны; отдельного сервера или ANN-индекса нет. При лимите прототипа в 2000 фрагментов это простая реализация; масштабирование предусмотрено через EmbeddingPort и порт репозитория. Семантическое качество русского языка ещё не проверено.

## Границы этапа

Старые записи не удаляются при миграции сессий. Исходная база памяти используется на месте. Профиль пользователя и состояние Лины пока остаются в прежних JSON, поэтому весь проект ещё не сводится буквально к двум файлам. Факты и эмоция теперь извлекаются одним JSON-анализом перед ответом; факты применяются после ответа. Долговечная очередь заданий — отдельный следующий этап. Между двумя базами нет общей транзакции. Поиск по нескольким зонам использует один вектор запроса; фильтр пользователя применяется до top-k.

## Пересмотр эмоционального опыта

Экстрактор может предложить `operation: reconsider` для конкретного UUID эмоционального эпизода. Код проверяет владельца, наличие эпизода, уверенность и дословное свидетельство из текущего сообщения. Повторная обработка одного сообщения ничего не меняет. Исходный текст и эмоция сохраняются; новое объяснение добавляется в историю интерпретаций и показывается в контексте как неопределённое. Вес влияния на отношение ограничен 0..1. Это интерпретация LLM с проверкой источника, а не доказательство намерений пользователя.

Проверка реальной модели: `.venv/Scripts/python.exe tools/check_memory_embeddings.py`. Скрипт не меняет пользовательскую память; тестовая база создаётся во временном каталоге.

## Инициализация при Start

Рабочий файл памяти: `data/memory.sqlite3` относительно корня LinaAI. В нём таблицы `core_versions`, `memories`, `vectors`. Отдельного файла FAISS/Chroma нет: используется точный поиск по векторам в SQLite.

Start теперь вызывает `initialize_index`: проверяет локальную embedding-модель, индексирует существующие воспоминания и выводит абсолютный путь, число записей и размерность в лог (`Vector memory ready`). Новые и изменённые воспоминания индексируются при сохранении, а не только при следующем поиске. При отсутствии воспоминаний таблица vectors остаётся пустой — фиктивные воспоминания не добавляются. Отсутствующая модель или зависимость показывается как ошибка запуска.

Подробности оптимизации и границы проверки: [PERFORMANCE_AUDIT.md](PERFORMANCE_AUDIT.md). Итоговый регрессионный набор — 92 теста. При проверке пользовательская база была пустой: 0 воспоминаний и 0 векторов; стартовая проверка не создаёт фиктивных записей.
