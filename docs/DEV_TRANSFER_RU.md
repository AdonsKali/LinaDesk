# Перенос доработок Лины в dev — 2026-10-29

Основа: `dev`, коммит `15c96fd`. Перенос выполнен выборочно после сравнения
функциональных отличий; существующие доработки ветки dev сохранены.

## Изменения

- Нейтральный лаунчер с вкладками «Общие», «Настройки», «Плагины».
  Права инструментов находятся на вкладке плагинов. Start/Stop, перезапуск,
  сворачивание и выход доступны независимо от выбранной вкладки.
- Перезапуск подключён к завершению приложения. Крестик скрывает окно в трей.
- Удалены неиспользуемые подключения к отсутствующему адаптеру оформления.
- Исправлен импорт отсутствующего CLI-адаптера, мешавший загрузке desktop-модулей.
- Пути LLM и проектора берутся из настроек с сохранением прежних значений по умолчанию.
  Добавлены настройки путей Vosk и эмбеддингов; флаг Economy передаётся провайдеру.
- Убран дублирующий ToolExecution перед проверкой разобранного вызова инструмента
  и искусственная задержка в пять секунд. Событие отправляет ToolEngine.
- Восстановлена регистрация существующего EchoTool. Остальные инструменты dev сохранены.
- Перенесены инструкции модели по фоновым заданиям, примеры плагинов,
  утилиты проверки памяти и документация памяти, речи и плагинов.

Данные пользователей остаются по путям `data/`, принятым в dev.
Персональные настройки, модели, базы, логи и ресурсы персонажей не переносились.
