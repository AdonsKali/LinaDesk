# Герта — тушь и сухая кисть

Оформление подключено к существующему GUI через модуль customization/ink_theme.py.
Структура вкладок, исходные контролы и обработчики команд переиспользуются.

- theme.json: шрифт, цвет текста, фон, доля ширины колонки, левый отступ, высота окна.
- background.png: чистый фон без текста/кнопок, 1536×1024; обновлённая анатомия ног.
- brush-*.svg: масштабируемые фактуры для кнопок, вкладок, полей и карточек.
- background-prompt.md: полный промпт генерации фона через встроенный image_gen.

Рисунок фона не содержит рабочих элементов управления. Все надписи и поля
рисует Qt; мышь проходит через декоративные слои. Стандартное оформление
восстанавливает исходные стили, размеры панели и отступы окна.

После редактирования конфигурации перезапустите приложение. PNG обязательно
переносится вместе с кодом: общие правила gitignore могут исключать изображения.


Active background: background-continuous.png — complete scene without a reserved UI region. Previous background.png retained for rollback. Generation prompt: background-continuous-prompt.md.
